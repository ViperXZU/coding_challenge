## 🧠 PATRÓN UNIVERSAL (Copia mental)

```python
# ═══════════════════════════════════════════
# 1. MODEL (datos)
# ═══════════════════════════════════════════
class MiModelo(models.Model):
    campo = models.CharField(max_length=200)
    usuario = models.ForeignKey(User, on_delete=models.CASCADE)
    created_at = models.DateTimeField(auto_now_add=True)
    
    def __str__(self):
        return self.campo

# ═══════════════════════════════════════════
# 2. FORM (validación)
# ═══════════════════════════════════════════
class MiForm(forms.ModelForm):
    class Meta:
        model = MiModelo
        fields = ['campo']

# ═══════════════════════════════════════════
# 3. VIEW (lógica)
# ═══════════════════════════════════════════
@login_required
def mi_vista(request):
    if request.method == 'POST':
        form = MiForm(request.POST)
        if form.is_valid():
            obj = form.save(commit=False)
            obj.usuario = request.user
            obj.save()
            return redirect('app:home')
    else:
        form = MiForm()
    
    objetos = MiModelo.objects.all()
    return render(request, 'app/template.html', {
        'objetos': objetos,
        'form': form
    })

# ═══════════════════════════════════════════
# 4. URL (routing)
# ═══════════════════════════════════════════
path('ruta/', views.mi_vista, name='mi_vista'),

# ═══════════════════════════════════════════
# 5. TEMPLATE (presentación)
# ═══════════════════════════════════════════
{% extends 'base.html' %}
{% block content %}
    <form method="post">
        {% csrf_token %}
        {{ form.as_p }}
        <button>Submit</button>
    </form>
    
    {% for obj in objetos %}
        <p>{{ obj.campo }}</p>
    {% endfor %}
{% endblock %}
```

## 📊 CONCEPTOS CORE

### El Flujo de Django:
```
   REQUEST
      ↓
   URL Dispatcher (urls.py)
      ↓
   VIEW (views.py)
      ↓
   MODEL (models.py) ←→ DATABASE
      ↓
   TEMPLATE (.html)
      ↓
   RESPONSE
```

### MVT Pattern:
```
M = Model     → Datos y BD
V = View      → Lógica (controlador)
T = Template  → Presentación (HTML)
```

### Ciclo de Desarrollo:
```
1. Escribir/Modificar Model
2. python manage.py makemigrations
3. python manage.py migrate
4. Crear/Modificar View
5. Crear/Modificar Template
6. Conectar URL
7. Probar en navegador
8. Git commit
```
